# BR-002 — Sequence numbers

## Goal
Let users number files while renaming, e.g. `IMG_4411.jpg` → `Trip_001.jpg`.

## Acceptance criteria
- AC-1: `Rename-ByPattern` gets a `-Sequence` switch. When set, the token `{n}` in `-Replacement` is replaced by a running number starting at `-Start` (default 1), zero-padded to `-Pad` digits (default 3).
- AC-2: Files are numbered in ascending order of their current name (ordinal, case-insensitive), so the result is deterministic.
- AC-3: Without `-Sequence`, `{n}` is left as literal text (backward compatible with BR-001 behaviour and tests).
- AC-4: Tests in `tests/Sequence.Tests.ps1` cover AC-1 to AC-3; all BR-001 tests still pass.

## Scope
- `src/BatchRename.psm1`
- new file `tests/Sequence.Tests.ps1`

## Out of scope
- Changing `scripts/*.ps1`.

## Verification
- `pwsh -NoProfile -File scripts/build.ps1`
- `pwsh -NoProfile -File scripts/test.ps1`
