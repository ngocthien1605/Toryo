# BR-001 — Rename files by regex pattern

## Goal
Add `Rename-ByPattern` so a user can batch-rename files in one folder with a regular expression.

## Acceptance criteria
- AC-1: `Rename-ByPattern -Path <dir> -Pattern <regex> -Replacement <string>` renames every file (not folder) directly in `<dir>` whose name matches `<regex>`, using `[regex]::Replace`, and returns one object per renamed file with properties `OldName` and `NewName`.
- AC-2: With `-WhatIf` nothing on disk changes, but the same `OldName`/`NewName` objects are still returned.
- AC-3: If two files would get the same new name, or the new name already exists, the function throws a terminating error whose message contains `Name collision` and renames nothing.
- AC-4: The new name is passed through `ConvertTo-SafeFileName`.
- AC-5: Tests in `tests/RenameByPattern.Tests.ps1` cover AC-1 to AC-4 using `New-TestFolder`.

## Scope
- `src/BatchRename.psm1`
- new file `tests/RenameByPattern.Tests.ps1`

## Out of scope
- Recursion into subfolders.
- Changing `scripts/*.ps1`.

## Verification
- `pwsh -NoProfile -File scripts/build.ps1`
- `pwsh -NoProfile -File scripts/test.ps1`
